TUSHAR VERMA — PORTFOLIO WEBSITE
================================

FILES
- index.html: page structure and portfolio content
- style.css: layout, colors, themes, and responsive design
- script.js: theme toggle, mobile navigation, reveal animations, and buttons
- documents/resume.pdf: your supplied resume
- images/profile.jpg: optional profile photo (add this yourself)

RUN LOCALLY IN VS CODE
1. Extract portfolio.zip to a folder.
2. Open the extracted "portfolio" folder in VS Code.
3. If needed, install the "Live Server" extension by Ritwick Dey.
4. Right-click index.html and choose "Open with Live Server".
5. Your browser will open the portfolio.

PROFILE PHOTO
Add a portrait image at images/profile.jpg. The site will show "TV" initials
until the photo is available. If your image has another filename, either rename
it to profile.jpg or update the src in index.html.

RESUME
Your supplied PDF is already copied to documents/resume.pdf. The Download Resume
button links to that relative path. If you replace the resume, keep the filename
or update the link in index.html.

CUSTOMIZE
- Update text and section content in index.html.
- Change colors and styling in style.css.
- Change interactions in script.js.
- Email and LinkedIn are taken from the supplied resume. No GitHub link was
  included, so no fictional repository links are shown.

TROUBLESHOOTING
- Missing photo: make sure the file is exactly images/profile.jpg (including
  capitalization); refresh the page.
- Resume download broken: confirm documents/resume.pdf exists and spelling matches.
- Theme not remembered: enable browser local storage; the toggle still works for
  the current visit if storage is blocked.
- Mobile menu not opening: make sure script.js is beside index.html and that
  the script tag at the bottom of index.html remains present.
- External Google Fonts need an internet connection; system fonts will be used
  if they cannot load.
